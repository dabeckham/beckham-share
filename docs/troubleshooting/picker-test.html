File picker test

A standalone diagnostic for the "upload asks for microphone / no file picker" problem on mobile browsers (see android-file-picker.md in this folder). Tap each Choose file below and note which one opens a real Files / My Files browser (vs Camera/Camcorder/Photos&Videos), and whether it still asks for microphone/camera. The picked file name shows in green to confirm it worked. Compare the cases to see how the accept attribute changes the chooser on your device.
